# Typfolio

A collection of presentation templates for [Typst](https://typst.app).

## Templates

| Template | Description | Status |
|----------|-------------|--------|
| [corporate](./corporate/) | Clean, professional slides for proposals and pitch decks | v0.1.0 |

## Usage

Each template is an independent Typst package. See the template's README for details.

```bash
# Compile a template's sample
typst compile corporate/template/main.typ output.pdf
```
